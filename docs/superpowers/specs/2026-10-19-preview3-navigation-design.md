# Preview 3 导航兼容修复

用户已同意修复，并允许在已连接手机上覆盖安装、仅测试导航；不得提交真实签到。

## 证据与范围

现有兼容签名 APK 能安装打开。只导航实测可进入小程序概览，识别结果未确认“最近使用”；手动进入最近列表后未确认完整目标名称。90 秒后仍在采样，返回应用结束后保存了 120 秒的导航记录。诊断采集的 UIAutomator 会临时影响无障碍，后续用截图及应用自身日志验证，不以它造成的服务断开作为产品故障。

## 方案

1. 将导航超时回调从带隐式 CoroutineScope 的调用处抽离，明确调用导航协调器停止方法，验证到期停止、取消旧计时器和新会话隔离。
2. 先增加仅本机保存的候选标签诊断：只保存“最近”“晚安”开头的短标签及位置，不记录聊天全文、姓名或学号，不保存应用截图。在真机确认实际识别差异后，只针对结构明确的入口修复，优先使用精确节点或区域识别；不得以截断名称、固定坐标或泛化模糊名称选择目标。
3. 保留连续两帧确认、同一窗口、新鲜帧、完整名称及仅导航不提交的限制。测试未通过不得称为稳定版本。
4. 版本号递增为 3 / 0.1.0-preview.3，沿用原签名。构建在唯一目录输出，保护既有产物。不上传设备原始记录、截图、私钥。验证后保存中文提交；Preview 发布标签只指向对应源码提交。

## 验收

回归测试覆盖到期回调、旧会话取消、入口标签识别、安全拒绝不完整名称。执行全部单元测试、构建及 APK v1/v2/v3、对齐、证书、版本校验。真机仅导航至少到达目标页并确认没有提交；失败则保留局部诊断并明确尚未解决。
